=============== chat_style_rules ===============
Source: /home/shobhitg/src/multi-team-support/.claude/skills/chat-message-style.md. Two strict rules for all player-facing text (player.print, helpers.broadcast, GUI labels). Rule 1: player names are never used raw — always wrapped via helpers.colored_name(name, player.chat_color), producing Factorio rich text [color=R,G,B]name[/color]; if only a name string is available, look the player up first. Exempt: log() calls, tooltips, internal identifiers. Rule 2: every message that mentions the word "team" must end with a grey force-name tag from helpers.force_tag(force_name), which renders as ` [color=0.50,0.50,0.50](team-N)[/color]` — always placed at the END of the sentence, after the period (e.g. `"You have left the team." .. helpers.force_tag(caller.force.name)`). Common idiom: cache both as locals (`local cn_player = helpers.colored_name(...)`, `local ft = helpers.force_tag(...)`) then concatenate. Broadcasts may carry a leading bracket category tag like "[Team] ". In the Players GUI, force names appear as a separate small grey label ` [force-name]` (font default-small, font_color {0.5,0.5,0.5}) rather than inline rich text. Implication for locale keys: messages are sentence-shaped with trailing composed fragments, so localised values need parameter slots (__1__ style) for the colored name and must leave room for the force tag appended after the sentence — the tag itself is code-composed rich text, not locale text.
